# nnDetection Results

Since the current version of `nnDetection` is mostly out-of-date:
- it relies on older CUDA drivers
- it requires an older version of common Python libraries
- it even uses the V1 of nnUNet
We do not list all the fixes that we had to do to get it working.
For more details about the CT normalization scheme, or disabling the image resampling along the depth, please refer to `nnUNet_Results.md` as both were identical.
